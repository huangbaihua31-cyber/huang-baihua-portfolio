# 黄柏华 · 创作集

此仓库保存已完成的第 11 版作品集。手机和触摸设备使用原生滑动卡片：单击放大图片或播放视频，“项目与资产”单独查看资料；返回列表保留浏览位置。大图支持左右滑动切换、放大后拖动，视频保留原生播放与进度控件。分类栏可横向滑动，关闭与返回按钮适配安全区域和横屏。桌面端保留 3D 圆柱轮播、液态折射 FlexCarousel、双击放大，以及首页视频填字、糖晶粒子与 ClickSpark 点击反馈。

## 访问与发布

- 首页：`index.html`。
- 图片、视频、简历及轮播脚本：`demo-assets/`。
- 在仓库 Settings → Pages 中选择 Deploy from a branch、main 分支、/ (root)，即可发布静态网站。
- `.nojekyll` 保留原有素材与文件路径，不需要安装 Node.js 或执行构建。

全部图片与项目视频使用相对路径，支持 GitHub Pages 的仓库子路径。页面包含 24 张海报、19 张品牌视觉、24 段视频与对应的创作资产；视频项目按分类连续浏览，配套图片保留角色、场景与道具分组。轮播支持方向键与 Enter；无法使用 WebGL2 时自动使用原有轮播。

背景开场素材改为本站缓存的 1080p 视频；234 张图片在放大时使用完整尺寸，16 段视频使用 720p/1080p 网页高清版本，两个长视频恢复较高码率备份；两个较大项目使用原画质分段加载，并保留高清下载。首页画布按需绘制，液态轮播按需加载附近图片，适配高像素密度屏幕。Google Fonts 保留原有字体声明。业务联系信息、个人照片与简历保持与已授权的公开作品集一致。
