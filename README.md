# 黄柏华 · 创作集

此仓库保存已完成的第 9 版作品集。网站增加 ClickSpark 点击反馈：八条短线向外散开并淡出，在首页和弹窗中均可显示，效果层不接收鼠标事件。首页目录两行文字保留视频填字，四个糖晶入口保留粒子交互。视觉作品使用 3D 圆柱轮播，视频项目与配套图片使用液态折射 FlexCarousel，支持双击放大图片或播放视频。

## 访问与发布

- 首页：`index.html`。
- 图片、视频、简历及轮播脚本：`demo-assets/`。
- 在仓库 Settings → Pages 中选择 Deploy from a branch、main 分支、/ (root)，即可发布静态网站。
- `.nojekyll` 保留原有素材与文件路径，不需要安装 Node.js 或执行构建。

全部图片与项目视频使用相对路径，支持 GitHub Pages 的仓库子路径。页面包含 24 张海报、19 张品牌视觉、24 段视频与对应的创作资产；视频项目按分类连续浏览，配套图片保留角色、场景与道具分组。轮播支持方向键与 Enter；无法使用 WebGL2 时自动使用原有轮播。

背景开场素材及 Google Fonts 沿用页面内的外部地址。业务联系信息、个人照片与简历保持与已授权的公开作品集一致。
